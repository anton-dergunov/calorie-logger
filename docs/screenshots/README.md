# Screenshots

The README links to these files. Capture them at a comfortable window size, with a realistic day
logged — a few foods across two or three meals, and targets set, so the table and the meters have
something to show.

| File | What it should show |
|---|---|
| `day-log.png` | The day view on a desktop: the four totals against targets, and the macro table with per-food rows, food pictures, and meal subtotals. The point of this one is the table. |
| `add-food.png` | The Add food sheet: the search field, your own catalogue below it, and the quantity panel on the right. |
| `camera.png` | The camera screen mid-scan, with the barcode offer showing. |
| `menu-bar.png` | The macOS menu bar popover open, with the three meters visible in the menu bar itself. Crop tightly; the README shows it at 420 px wide. |
| `phone-log.png` | The day view on a phone, showing that the table survives at that width with the short column labels. |

Keep them in light mode for consistency, and avoid capturing anything you would not want public —
the sign-in screen, a server address, or an email.
